# 分子证伪 · AMZN Q1 CY2026

> **Call Date**: April 29, 2026 | **链位置**: 中游 (swing link)
> **一句话定位**: AWS AI 营收 $15B+ run rate + Tranium 自研芯片 $50B 等效年化收入 + capex $43.2B Q1 → 中游第二大 swing link 确认走强

---

## 第0步：定位链条位置

**中游 (swing link)** — 超大厂/云。AMZN 的 AWS 与 MSFT Azure、GOOGL Cloud 共同构成中游云基础设施层。AWS backlog $364B 直接对应上游算力采购，Tranium 自研芯片影响上游 GPU 需求结构。零售/广告业务体量大但对链边际信号弱。

### B. 前瞻指引

- **Q2 收入指引**: $194–199B (+14–17%)
- **AWS 增速方向**: 供给约束仍是瓶颈（暗示增速天花板由产能决定，非需求）— Andy: "we continue to be supply-constrained on several key AWS products"
- **Capex 方向**: Q2 capex 暗示 → Q1 $43.2B 已为历史新高，Andy 暗示全年"significantly higher"水平
  - Andy: "we expect capex to increase significantly in 2026"
- **Tranium 产能 ramp**: 正在加速，Anthropic/OpenAI/Meta 均已采用
- **2027 信号**: 未给出具体 capex 数字，但 backlog $364B + 供给约束 = 隐含高强度持续投入

**capex 评判**: **加速中**。Q1 $43.2B（年化 ~$173B），Andy 明确全年大幅增加。与 MSFT ~$190B、GOOGL $180-190B 形成合力。

### D. 传导证据（上游→下游变现）

| 证据 | 硬度 | 出处 |

### E. 风险与对冲措辞

- **零售利润率压力**: 工资上涨 + 关税不确定性（Brian 提及但不量化）
- **供给约束**: 明确承认影响增速上限
- **Q&A 回避清单**: 对 Brent Thill 问 AWS margin trajectory，Brian 给定性回答但未给量化路径；对关税对零售影响的量化问题仅给方向性描述
- **Advantum 量子芯片**: 刚发布但未商业化，纯前瞻

## 跨链合力提醒

- **AMZN capex + MSFT $190B + GOOGL $180-190B** = 中游三巨头 capex 年化 ~$550B+，是上游 NVDA 最强需求背书
- AMZN Tranium 自研芯片 $225B commitments → 不代表上游 GPU 需求减弱，而是 total AI spend 池子在涨（自研芯片是增量 infra，不是替代）
- AWS 28% growth + 37% OM = AI capex 扩张同时利润率在改善 → 反驳 "capex 无回报" 叙事
- AMZN 是唯一同时在上游算力池（Tranium）和中游云基础设施操作的大厂 → 平台公司一体化的 AI 变现模型
