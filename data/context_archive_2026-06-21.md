## 一、SOFR 期货链：完整验证 → 负结论（机械信号）+ 正用法（人眼）

### 数据
- 淘宝购入 SR3 历史数据，已验证：2018-05-07→2026-06-17，84 个合约，2045 交易日，0 异常、0 断档，每日曲线点数 ≥19。**无 Eurodollar 污染**（文件名写 2008 是模板默认，实际从 2018 SOFR 期货上市开始）。可确认收货。
- 生成物（在 /mnt/user-data/outputs/）：
  - `sr3_long.csv`（84 合约重组长表，58823 条）
  - `sr3_curve_features.csv`（2045 天特征：近月利率/隐含终点/终点到期月/利率见顶时点/降幅bp）
  - `sofr_sr3.csv`（手动填报模板，10 个合约）+ `sofr_curve_spec.md`（计算规格，现已 MOOT）

### 验证结论（负 — 不做进系统当方向信号）
- **验证1（SOFR降幅 vs 实际降息）**：cut_to_terminal_bp 从 2023-01(177bp) 到 2024-09 实际降息(184bp) 之间常年乱晃 130-220bp，**对降息时点极不准**，"提前两年 price in" = 喊了个寂寞；
- **验证2（SOFR vs 2s10s 互相关）**：最优 lag=-120 交易日，corr=-0.40 → **2s10s 领先 SOFR 约半年，SOFR 反而滞后**；
- **核心教训**：期货隐含曲线 ≠ 前瞻信号。市场 price in 的东西常年存在、对时点不准。

### 关键澄清（SOFR 的正确定位）
- **SOFR = 2s 短端的精准表达**（高清版），不是 2s10s 的劣质替代。它和 2s10s 分工：SOFR 看短端细节，2s10s 看短端 vs 长端的关系。我最初否 SOFR 是拿它和 2s10s 比"谁预测降息准"——错误的比较。
- **SOFR 滞后 ≠ SOFR 是噪音**。领先/滞后是时间，信号/噪音是质量，两回事。
- **数据源探索**：IBKR API（ib_insync 装好但 Gateway 运维太重，放弃）→ 改手动 CSV（每天填 10 个 SR3 价格）→ 最终因负结论，CSV 也不必填。TradingView forward curve 视图直接能看（人眼用），但无数据 API（DevTools 抓数据违反 ToS，别做）。

### SOFR 的正用法（人眼，不进系统）
- **读法**：隐含利率 = 100 − 合约价格。曲线形态反着读（价格↓=利率↑）。
- **当前曲线（6/18）**：利率升到 Mar-27（~4.18%）见顶，之后温和回落到 2029（~3.87%，只降31bp）。2029 以后是期限溢价+无流动性的噪音，别读成预期。**有效区间只有近端 2-3 年。**
- **看斜率变化**（方向 2s10s 给，SOFR 只看陡峭/平坦变化）：看变化不看绝对值（绝对值混期限溢价），看趋势不看单日（人眼自带平滑）。
- **6/18 vs 6/17 力度递减**（边际变化变窄=钝化）可能预示顶峰——但两天样本太小，需连续观察。

## 二、cooling 验证 → 发现两个真缺陷（要修）

### cooling 算法（用户提供）
```
real_yield_nowcast < 2.00% → cooling_counter += 1 (上限3)
real_yield_nowcast ≥ 2.00% → cooling_counter = 0 (归零)
real_yield_nowcast = (US10Y − BEI) − basis_median
  US10Y = ^TNX/10; BEI = T10YIE; basis_median = 252日滚动中位数((^TNX/10−T10YIE)−DFII10)
```

### 验证结果
- **basis 校准完美**：nowcast 公式 vs 直接 DFII10 差异 = 均值0.000/标准差0.000。**用户的 basis 校准设计是对的**（实时 ^TNX 逼近官方 DFII10，逼得严丝合缝）；
- **缺陷1：2.00% 门槛历史失效**。真实利率历史中位数 1.00%，81% 时间低于 2%，cooling 80% 时间满格（3/3）。**门槛太高，几乎总触发**。现在的 2.23% 是历史罕见高位（仅18%时间这么高）；
- **缺陷2：TLT 触发条件冗余**。原触发 = `cooling≥2 + DFII10破2%`，但 cooling≥2 ≈ DFII10<2%（因为 nowcast≈DFII10），**两条腿是同一件事，不正交**——违反用户自己的"AND-gate 要正交"原则。且历史上 80% 时间满足，无区分力。

### 修复方向（待做）
- **cooling 门槛**：从"2% 绝对门槛"改成"real yield 回落动作"（滚动 z-score / 相对近期高点回落），自动适应体制，绕过"用哪段历史"的纠结；
- **TLT 触发重设计**：两条正交腿 —— 腿1=真实利率回落动作（不用绝对门槛），腿2=独立信号（信用利差，区分软硬着陆）；
- **数据**：DGS10/DFII10/T10YIE/EFFR/DFEDTARU 都已下载，FRED 免费，覆盖 2018-2026。

## 四、宏观框架（本次想通的核心思想资产）

### 4.1 Fed put 的精确定义（三层，逐步抠出来的）
- **不是**"市场预期 Fed 要鸽"（太粗）；
- **精确**：Fed put = 市场预期"Fed 在威胁金融稳定时会兜底转鸽" = 对**条件性危机兜底**的信念；
- **宋老师的更狠版**："Fed put 本质不存在，只是 Fed 履行第三 mandate（financial stability）的副产品"——Fed 从不为资产价格托底，只在体系要崩时救体系；
- **三层要分清**：①Fed 实际立场（现实）②市场预期 Fed 近期立场（=SR3 读的，现在 price in higher-for-longer）③Fed put（=市场对危机兜底的信念，比②更深一层）；
- **操作含义**：不用问"市场预期 Fed 兜底吗"（玄学），直接问"金融稳定受威胁了吗"——受威胁（信用冻/回购爆）= Fed 救体系；没威胁（估值杀）= Fed 不管，你扛着。判断工具 = 信用利差/SOFR-IORB。

### 4.2 软硬着陆判别（操作主框架，比 Fed put 抽象更可用）
三维交叉判断软硬：
- **SR3 曲线** = put 的时间/力度（市场预期）；
- **2s10s 形态** = put 的性质（政策性 vs 系统性失控）；
- **信用利差** = put 的紧迫性（估值杀 vs 管道危机）；

```
软着陆: SR3温和下修 + 2s10s牛陡 + 信用稳 → 加AI
硬着陆-利率框架: 2s10s熊陡（长端失控）→ 长久期降仓
硬着陆-衰退: 2s10s牛平 + 信用走阔 → H接货
陷阱: SR3下修(看似好)+ 2s10s牛平(实为避险) → 戳穿假软着陆
```
- **2s10s 是 SR3 的测谎仪**：同样 SR3 下修，配牛陡（软）还是牛平（硬），结论相反；
- **背离捕捉是软硬判断的免费副产品**：做好软硬状态判断后，对照市场情绪（股价/SR3），背离自己浮现。不用单独建。

### 4.3 SR3 用法的最终落点（宋老师点醒）
- SR3 = rates traders 对 policy rate 的**共识下注**，"这个定价不一定对"，edge = 判断共识对错；
- **宋老师的论点（定价视角，不是政策方向）**：
  1. 市场漏 price 了 task forces 这个因素；
  2. 即便认可加息方向，短端也 over priced（定太高）；
  3. 流动性来源美国（加息是价格工具≠抽流动性数量，那是缩表的事；美国是净供给方）→ 市场怕加息收紧流动性而高定价短端 = 过度反应；
  4. 联储确实 behind the curve（"加一次都嫌少"= 落后需追），但 behind the curve 的追赶式加息不可持续，加完反转 → 中远端 higher-for-longer 是 over priced；
- **核心可观测靶子**：SR3 的 **Z6-M7（Dec26-Jun27）是否向 6/16 曲线修复**。这是宋老师"中远端 over priced/沃什虚晃"论点的最早验证信号；
- **但"修复"有两种，含义相反**：良性修复（沃什虚晃+软着陆，信用稳→布局）vs 恶性修复（衰退式，信用爆→逃）。光看 SR3 回落区分不了，**必须配信用利差判性质**。

### 4.4 货币财政组合：当下美国最像什么（看清范式）
**当下 = 财政主导范式的过渡期（货币还在抵抗）**
- 货币端：偏紧（沃什鹰派、缩表、ON RRP见底）；
- 财政端：扩张 + **产业政策定向投放**（CHIPS、入股Intel、AI基建）；
- 政治端：行政侵蚀央行独立性（压鲍威尔）= 财政主导倾向；

**最像**：1940年代美国（财政主导、央行从属、国家动员战略产业），但产业政策执行方式带**当代中国国家资本主义色彩**（定向入股/补贴战略产业）。
- **独特性**（两个模板都没有）：财政已主导，但货币端还在抵抗（老美联储守独立性）——是过渡期不是完成时；

**核心矛盾 = 财政主导 vs 货币抵抗的拉锯**：
```
货币屈服(降息配合财政) → 完整财政主导 → real yield回落 → 
  AI得到缺的"货币宽松"那条腿 → 2015式持久繁荣（但终有通胀代价+范式结束风险，如1951协议）
货币守住(higher-for-longer) → 财政松货币紧的张力 → real yield高位 → 
  AI脆弱 → 滞胀风险（60-70年代式）
```
- **你前面争论的"会不会降息" = 这个框架下的"财政主导会不会压服货币抵抗"**；
- **历史教训（1940年代）**：财政主导一旦启动，货币端往往最终屈服（美联储1942-1951压低利率配合财政，1951协议才重获独立），代价是通胀；
- **你的指标本质上在监控这场拉锯谁赢**：SR3向6/16修复+real yield退潮=货币在屈服（向2015式繁荣）；SR3顶住+real yield高位=货币在守住（向滞胀脆弱）。

### 4.5 DCF 分子分母的正确挂法（厘清过的）
- **不是**"2s=分子、10s=分母"（错，2s更像分母/贴现率，10s是分母+分子混合）；
- **正确**：两套系统对应分子分母——
  - **ABCD 利率/流动性指标（2s10s、DFII10、SR3、SOFR-IORB）= 分母（贴现率/资金成本）**；
  - **九公司"两面看"监控（AI bookings、营收、变现）= 分子（现金流/增长）**；
- **AI = 分子靠预期撑 ÷ 分母高位压着**，双重脆弱。分母松（cooling/DFII10触发）或分子证伪（九公司监控）是两个不同转折信号。这就是"分子证伪挂九公司不挂ABCD"的底层逻辑。

### 4.6 房地产类比（看清当下用，不作买入模板）
- **2015中国房地产**：政府定向放水（PSL/棚改）托房地产，但在**货币大宽松（5次降息+降准，一年期贷款5.6%→4.35%）**环境下——分母顺风。美国AI现在缺这条"货币宽松"的腿，只有财政托底一半，更脆弱；
- **2008中国房地产**：崩30%→四万亿暴力救市（利率打7折+首付降20%）→2009房价翻倍V型反转→**但最终2022恒大碧桂园暴雷**。"先崩后救V反转"正是 H=45% 接货想抓的剧本，但 V 反转是新泡沫起点，不是永久繁荣；
- **共同终点**：两个类比都终将"回归地心引力/最终出清"——**都是"谨慎持有+留弹药"的理由，不是"乐观加仓"的理由**；
- **关键警示**：中国政府能托房价（封闭市场+绝对意愿），美国政府托不住AI股价（开放市场+只托产业不托估值）。**产业托底 ≠ 估值不跌**。
